# Fontes citadas no documento "Indicadores Campo Mourão 2026" (IPPLAN)

Levantamento de todas as fontes que o próprio PDF cita (linhas "Fonte:" e notas), agrupadas por seção. A coluna **Fonte primária** é o órgão que produz o dado; muitas tabelas dizem "Elaborado pelo CODECAM apud X" ou "IPARDES apud X": nesses casos o dado deve ser buscado em **X**, que é a fonte oficial. A coluna **Códigos** liga a tabela ao catálogo (`csv/indicadores-ipplan.csv`).

Atenção a três problemas do PDF, para o relatório do projeto:
1. As tabelas "Panorama Econômico 2018 a 2025" repetem os dados de 2017 (coluna Data = 2017).
2. Há títulos e anos que não batem com a fonte (agências bancárias "2025" com fonte "posição dez/2016"; população "estimada 2025" com fonte "atualizado em 22/12/2023"; "RAIZ" no lugar de RAIS).
3. Algumas tabelas não citam fonte nenhuma (marcadas "sem fonte citada").

## Resumo por órgão (onde buscar)

| Órgão | Indicadores | Como acessar |
|---|---|---|
| IBGE | população, PIB, VAB, Censo, PAM, PPM, Censo Agropecuário | API de agregados (script `baixar_ibge.py`) |
| IPARDES | compilados de quase tudo (finanças, PIB, saúde, eleitores, agropecuária) | download manual das tabelas por tema; ver GUIA-DADOS |
| MTE (RAIS e CAGED) | emprego e estabelecimentos | Base dos Dados ou bases do MTE |
| STN/SICONFI | receitas e despesas municipais | API/portal SICONFI |
| SEFA-PR | ICMS, ICMS Ecológico, VAF | portal da Fazenda do Paraná |
| FIRJAN | IFGF e IFDM | portal FIRJAN (consulta por município) |
| PNUD/IPEA/FJP | IDHM, fecundidade | Atlas Brasil |
| MEC/INEP e QEdu | matrículas, escolas, IDEB | microdados INEP / Base dos Dados |
| DATASUS e SESA-PR | saúde e mortalidade | TabNet/DATASUS |
| BACEN | agências, crédito rural | portais do BACEN |
| SEEC-PR | bibliotecas e equipamentos culturais | via IPARDES |
| ANM/DNPM | CFEM | portal da ANM |
| DERAL/SEAB-PR | VBP agropecuário | portal da SEAB |
| DIEESE | 13º salário | estudos do DIEESE |
| Prefeitura e IES | conselhos, escolas municipais, ensino superior | solicitação direta |
